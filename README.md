# سامانه مدیریت و استخراج خودکار پرونده‌های تسویه شده و تراکنش‌ها
### پنل ادمین پارک‌وی کالا (Parkway Kala)
**آدرس پنل:** https://admin.parkwaykala.ir

این پروژه یک نرم‌افزار کامل، امن و خودکار بر پایه **React + TypeScript** و **Node.js + Express** برای مدیریت و استخراج روزانه پرونده‌های تسویه شده و تراکنش‌ها، تبدیل مبالغ ریال به تومان، تولید کارت‌های گرافیکی تسویه اقساط و ایجاد بسته‌های فشرده (ZIP) است.

## ۱. ویژگی‌ها و قابلیت‌های اصلی <a name="ویژگی‌ها"></a>
- **تمرکز انحصاری بر دو بخش اصلی:** «پرونده های تسویه شده» و «تراکنش ها» بدون امکانات غیرضروری
- **ورود خودکار و امن:** استفاده از Playwright و نگهداری رمز عبور منحصراً در لایه Backend
- **تبدیل ریال به تومان:** محاسبه دقیق طبق فرمول `Toman = Rial / 10`
- **تولید خودکار کارت گرافیکی:** تولید فایل PNG با ستون زرد ردیف، تاریخ‌های پرداخت به رنگ قرمز، مبالغ به رنگ آبی و نام‌گذاری استاندارد:
  `[نام_مشتری]_پرونده_[شناسه].png`
- **بسته‌بندی خودکار ZIP روزانه:** تجمیع تمام فایل‌های روزانه به صورت `reports_1405-01-25.zip`
- **پایگاه داده مستقل:** ذخیره‌سازی وضعیت‌ها با شناسه یکتای پرونده جهت جلوگیری از پردازش تکراری (Duplicate Prevention)
- **بخش تاریخچه سبک و لاگ‌ها:** گزارش تعداد پرونده‌های اسکن‌شده، موارد جدید، تصاویر تولید شده و خطاها

## ۲. امنیت و متغیرهای محیطی <a name="امنیت"></a>
اطلاعات ورود به هیچ وجه در فرانت‌اند، کلاینت یا مخزن Git ذخیره نمی‌شوند.

یک فایل با نام `.env` در ریشه پروژه بر اساس `.env.example` بسازید:
```bash
cp .env.example .env
```

محتوای فایل `.env`:
```env
# نام کاربری و رمز ورود پنل ادمین
ADMIN_USERNAME="your_admin_username"
ADMIN_PASSWORD="your_secure_password"

# آدرس پنل
PARKWAY_ADMIN_URL="https://admin.parkwaykala.ir"

# زمان اجرای خودکار هر شب (فرمت HH:mm)
SCHEDULE_TIME="23:00"
TIMEZONE="Asia/Tehran"

# محل ذخیره گزارش‌ها
STORAGE_PATH="./storage"
PORT=3000
```

> **نکته امنیتی:** اگر سایت نیاز به حل کپچا (CAPTCHA) یا کد پیامکی (OTP/MFA) داشته باشد، سیستم به صورت هوشمند فرآیند خودکار را متوقف کرده تا ورود با نظارت شما انجام گیرد و هیچ رمز عبوری فاش نشود.

## ۳. پیش‌نیازها و نصب سیستم <a name="نصب"></a>

### نصب Node.js (نسخه 20 یا بالاتر):
روی لینوکس (اوبونتو / دبیان):
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### نصب وابستگی‌های پروژه:
```bash
npm install
```

### نصب Playwright و مرورگر Chromium:
```bash
npx playwright install chromium
# در صورت نیاز به پیش‌نیازهای لینوکس:
npx playwright install-deps
```

## ۶. اجرای دائمی روی سرور / VPS با PM2 <a name="اجرای-دائمی-pm2"></a>
برای اینکه فرآیند خودکار حتی پس از بستن ترمینال یا ری‌استارت سرور همیشه فعال بماند:

۱. نصب PM2 به صورت سراسری:
```bash
sudo npm install -g pm2
```

۲. اجرای پروژه با PM2:
```bash
pm2 start "npm run start" --name "parkway-automation"
```

۳. تنظیم اجرای خودکار پس از بوت سرور:
```bash
pm2 save
pm2 startup
```

۴. مشاهده لاگ‌های فرآیند:
```bash
pm2 logs parkway-automation
```

## ۷. اجرای دائمی با Docker <a name="اجرای-دائمی-docker"></a>
یک فایل `Dockerfile` استاندارد:
```dockerfile
FROM node:20-bullseye-slim

WORKDIR /app
COPY package*.json ./
RUN npm install

# نصب playwright chromium
RUN npx playwright install --with-deps chromium

COPY . .
RUN npm run build

EXPOSE 3000
CMD ["npm", "run", "start"]
```

ساخت و اجرا:
```bash
docker build -t parkway-automation .
docker run -d -p 3000:3000 --env-file .env --name parkway-app -v $(pwd)/storage:/app/storage parkway-automation
```

## ۸. تنظیم زمان‌بندی روزانه (Scheduler) <a name="زمان‌بندی"></a>
زمان پیش‌فرض اجرای اسکریپت هر شب ساعت **23:00** به وقت تهران است.
شما می‌توانید:
- از طریق فایل `.env` با تغییر متغیر `SCHEDULE_TIME=23:00`
- یا مستقیماً از داخل رابط کاربری برنامه با کلیک بر روی آیکون چرخ‌دنده یا ساعت هدر، زمان مورد نظر را تنظیم کنید.

همچنین هر زمان که مایل باشید، دکمه **«استخراج و تولید جدید»** در بالای صفحه بلافاصله فرآیند را برای پرونده‌های جدید آغاز می‌کند.

## ۹. محل ذخیره‌سازی تصاویر و فایل‌های ZIP <a name="محل-ذخیره‌سازی"></a>
- **تصاویر کارت‌ها:**
  مسیر: `storage/reports/[نام_مشتری]_پرونده_[شناسه].png`
- **فایل‌های فشرده روزانه:**
  مسیر: `storage/zips/reports_[تاریخ].zip`
- **پایگاه داده رکوردهای محلی:**
  مسیر: `storage/parkway_data.json`

## ۱۰. نحوه پردازش مجدد پرونده (Reprocess) <a name="پردازش-مجدد"></a>
اگر پرونده‌ای نیاز به محاسبه مجدد اقساط یا صدور تصویر جدید داشت:
1. در جدول **«پرونده های تسویه شده»** روی آیکون چرخش فلش (Reprocess) در ستون عملیات کلیک کنید.
2. یا پرونده را باز کرده و در مودال جزئیات، دکمه **«تولید مجدد کارت (Reprocess)»** را بزنید.
سیستم پرونده را دوباره ارزیابی کرده و کارت جدید را جایگزین می‌کند.

## ۱۱. اجرای تست‌های خودکار <a name="تست‌ها"></a>

```bash
npm run test
```
این دستور فایل `backend/src/tests/automation.test.ts` را به صورت مستقل اجرا می‌کند.
